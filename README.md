# 매일 영단어 학습

121–160번 40개 단어: 영어 읽기 + 한국어 뜻, 영어 → 한글, 한글 → 영어·스펠링.

https://HongTaeHwa.github.io/day04-vocab/

## Android 태블릿 사용

1. 위 HTTPS 주소를 Chrome에서 직접 엽니다.
2. `① 마이크 사용 권한 요청`을 누르고 브라우저에서 허용합니다.
3. `② 음성 인식 시험`을 눌러 한국어로 말합니다.
4. 시험 방식·단어 범위를 선택하고 시험을 시작합니다.

권한은 자동 승인할 수 없습니다. Chrome 사이트 설정의 마이크 권한과 Android의 Chrome 앱 마이크 권한을 모두 확인하세요. 음성 인식은 브라우저·인터넷 연결·기기 정책의 영향을 받으며 HTTPS 배포만으로 모든 기기에서 성공을 보장하지 않습니다. 실패하면 키보드 음성 입력 또는 직접 입력을 이용할 수 있습니다.

음성 인식 서비스는 브라우저 제공업체의 서버에서 음성을 처리할 수 있습니다. 앱 자체에는 녹음 저장·음성 업로드 서버가 없습니다. 읽기 판정은 인식된 텍스트를 비교하며 전문 발음 평가가 아닙니다.

## 모름·점수 기록·음성 수정

한글 → 영어 시험에서 `알파벳으로 철자 말하기`를 누르면 영어 알파벳 이름을 인식해 철자로 변환합니다. 예: `C A T` → `cat`. 단어를 통째로 읽는 발음 연습은 선택 사항이며 스펠링 점수에 영향을 주지 않습니다. 알파벳을 확실히 변환하지 못하면 인식 원문을 남기고 직접 수정하도록 안내합니다.

갤럭시에서는 정답 입력칸에 삼성 키보드의 손글씨 모드 또는 지원 기기의 S펜으로 텍스트 입력 기능으로 글자를 넣을 수 있습니다. 영어 철자는 English 입력 언어를 선택하세요. 손글씨 인식은 기기에서 처리하며 웹앱은 변환된 텍스트를 채점합니다. 앱이 기기 설정이나 손글씨 모드를 자동으로 전환하지 않습니다. 지원 여부와 메뉴는 기기·One UI 버전에 따라 다릅니다. 실제 S펜 기기에서의 인식은 별도 확인이 필요합니다.

- 음성 인식 결과는 입력칸에 먼저 표시합니다. 잘못 인식된 글자를 수정한 뒤 `읽기 채점` 또는 `정답 확인`을 눌러 채점합니다.
- `모름 · 정답 보기`를 누르면 정답을 보여주고 모르는 단어를 오답으로 기록합니다. `다음 문제`를 누르면 진행합니다.
- 기본 예제의 전체 범위는 121~160번의 서로 다른 40개 문제이며, 추가한 세트는 저장한 단어 수에 맞춰 출제합니다. 부분 범위는 10문제, 오답 복습은 선택한 오답 개수입니다. 진행 중에는 시험 방식·범위·시작 버튼이 잠겨 초기화를 방지합니다.
- 완료한 시험은 날짜, 방식, 범위, 점수, 오답 및 모름 개수와 함께 브라우저에 누적 저장됩니다. 중단한 시험은 저장하지 않습니다.
- 기록별 오답 재시험, 개별·전체 삭제, CSV 내려받기를 지원합니다. 점수는 정답 수 / 문제 수 × 100을 반올림해 표시합니다. 모름 개수는 오답 개수에 포함됩니다.
- 기록은 같은 기기·브라우저에만 저장되며 기기 간 동기화는 지원하지 않습니다. 브라우저 데이터를 지우면 기록도 없어지므로 CSV로 보관할 수 있습니다. 배포 전 시험 기록은 소급 생성되지 않습니다.

## 배포

`main` 브랜치의 루트 디렉터리를 GitHub Pages 게시 소스로 사용합니다. 진입점은 `index.html`이며 빌드 단계가 없습니다. 사진 인식 도구는 사용 시 CDN에서 내려받습니다.

원본 `day04_voice_vocab_permission_request.html`의 40개 단어와 기본 화면을 유지하고, 권한·음성 인식 흐름 및 오류 안내를 보완했습니다.

## 매일 영단어: 사진 기반 학습 세트

상단에서 새 세트 이름을 입력하고 사진(최대 6장, 각 10MB)을 선택하거나 촬영합니다. `사진에서 단어 추출`은 Tesseract.js 5.1.1의 영어·한글 OCR을 브라우저에서 실행합니다. 사진은 원본 비교 화면에서만 사용하며 서버나 localStorage에 저장하지 않습니다. 도구·언어 데이터는 이 사이트에 포함되어 있으며 외부 CDN 연결 없이 내려받습니다. 최초 실행에는 인터넷이 필요합니다.

추출 결과는 **번호 / 영어 / 뜻 / 허용 답안**을 탭으로 구분한 한 줄씩 편집합니다. 별칭은 `|`로 구분합니다. 직접 `apple 사과`처럼 입력할 수도 있습니다. 표·다단·예문·발음은 잘못 인식되거나 누락될 수 있으므로 사진과 비교하고 불필요한 행을 지우고 누락 단어를 추가하세요. 확인란을 체크한 후 저장하며 시험은 자동 시작되지 않습니다. 발음 정보를 임의로 생성하지 않습니다.

세트를 선택하면 해당 세트의 오답과 시험 이력을 표시합니다. 삭제한 세트의 이력은 계속 표시하며 당시 정답 스냅샷으로 복습합니다. 편집 전 이력도 당시 단어를 유지합니다. 뜻은 대표 뜻 또는 허용 별칭 전체 일치로 채점합니다. 다른 뜻을 허용하려면 별칭을 추가하세요.

`전체 백업 JSON`은 세트·시험 이력·오답을 함께 내보냅니다. 가져오기는 새로운 ID로 복사하여 기존 세트를 보존합니다. 다른 기기로 자동 동기화되지 않습니다. 저장 오류가 표시되면 JSON을 먼저 백업하세요. 기존 DAY04 기록은 원본 키를 삭제하지 않고 `daily_vocab_legacy_backup_v1`에 백업 후 변환합니다. 손상된 저장 자료는 덮어쓰지 않습니다.

## 홈 화면 설치와 오프라인

Chrome 메뉴 → 홈 화면에 추가 / 앱 설치를 사용합니다. 브라우저가 설치 이벤트를 제공하면 설치 버튼도 표시합니다. Android용 192/512 PNG와 maskable 아이콘 및 Apple touch icon을 포함합니다. manifest의 경로는 기존 `/day04-vocab/`를 유지합니다.

앱 셸과 저장된 세트는 한 번 접속한 뒤 오프라인으로 사용할 수 있습니다. 최초 OCR 데이터 다운로드와 외부 음성 인식은 오프라인 지원을 보장하지 않습니다. 앱 업데이트 안내가 나오면 시험을 마치고 열린 앱 탭을 모두 닫은 후 다시 엽니다. 앱 셸을 변경할 때 `sw.js`의 CACHE 버전을 올리세요. 설치가 마이크 권한을 대신하지 않습니다.

## 개발 및 브라우저 검증

빌드나 앱 런타임 패키지 설치 없이 정적 서버로 실행합니다. `/workspace`에서 `python3 -m http.server 8000 --bind 127.0.0.1`을 실행하면 기존 Pages 경로로 테스트할 수 있습니다.

`tests/browser.cjs`는 Playwright가 설치된 환경에서 실행합니다. Chromium이 이미 있으면 `CHROMIUM_PATH=/usr/bin/chromium node tests/browser.cjs`를 사용하며, 기본 URL은 서버의 `/day04-vocab/`입니다(`APP_URL`로 변경 가능). 테스트는 별도의 브라우저 컨텍스트에서 실행하므로 실제 사용자 저장 자료에 영향을 주지 않습니다.

실제 교재 사진의 OCR 정확도와 Android 태블릿의 설치·마이크·S펜·음성 철자 인식은 실기기 확인이 필요합니다. 사진 검증용 개인정보 자료를 공개 저장소에 커밋하지 마세요.

추가 검증: `tests/pwa.cjs`는 화면 폭·오프라인 셸·OCR 오류/취소를 확인하고, `tests/ocr.cjs`는 합성 영어+한글 이미지 두 장을 실제 OCR 엔진으로 인식하여 중복 검토·수정·저장·시험 흐름을 확인합니다. OCR 테스트는 저장소에 포함된 인식 엔진과 언어 데이터를 사용하며 외부 HTTPS 요청을 차단합니다. 실제 교재 사진 정확도를 대신하지 않습니다.

사진 추출 버튼을 누르면 즉시 시작 안내가 표시됩니다. 도구 다운로드는 30초, 인식 데이터 준비는 90초, 사진 한 장 인식은 120초 안에 응답이 없으면 오류와 재시도 안내를 표시합니다. 사진은 긴 변 2000픽셀 이하로 줄여 인식하며 원본 사진은 저장하거나 전송하지 않습니다. 준비 중에도 취소할 수 있습니다. `tests/ocr-failures.cjs`는 다운로드/초기화 지연, 초기화 취소, 오류 안내를 확인합니다.

앱 상단에는 화면 버전과 초기화 상태가 표시됩니다. 사진 선택 안내가 나타나지 않으면 `새 버전 불러오기`를 사용하세요. 저장한 자료는 유지되며 미저장 입력은 확인 후 초기화됩니다. `앱 점검`은 사진 수·추출 버튼 연결 상태·화면 처리 오류를 표시합니다. `tests/app-update.cjs`는 이전 스크립트 캐시 우회, 초기화 실패 표시, 갱신 시 저장 자료 보존을 확인합니다.
