# 매일 영단어 (daily-vocab)

사진으로 만드는 나만의 영단어장. 교재 사진을 올리면 AI가 번호·영어·뜻·발음·허용 답안을 정리해 주고, 영어 단어만 있는 사진이나 직접 적은 영어 단어는 AI 사전이 뜻·발음을 채워 줍니다. 아이는 말하기·쓰기로 시험을 보며 틀린 단어를 복습합니다.

https://hongtaehwa.github.io/daily-vocab/

- 아이 화면: **홈 → 시작 → 풀기 → 결과**. 중간에 **쉬기**를 누르면 나중에 **이어서 하기**가 되고, **그만하기**를 누르면 푼 데까지가 ‘중단’ 기록으로 남습니다.
- 아이 기기의 설정 탭에는 **AI 연결**, **가족 기록함**(아이 기기 연결), 마이크 점검, 백업, 앱 정보가 모여 있습니다. 세트는 사진 또는 표 편집으로 만들고 이름을 바꿀 수 있습니다.
- 보호자 폰에는 아이용 앱과 따로인 **보호자 앱**(https://hongtaehwa.github.io/daily-vocab/parent.html, ‘영단어 보호자’ 아이콘)을 설치해 **오늘 · 아이들 · 설정** 세 화면에서 아이들의 기록·세트·오늘의 단어를 관리합니다(아래 ‘보호자 폰에서 아이들 기록 보기’).
- 모든 자료(세트·기록·틀린 단어)는 기기의 브라우저에 저장됩니다. 보호자가 아이 코드로 연결해 주면 **시험 기록(점수·틀린 단어)만** 가족용 AI 서버로 보내져 보호자 앱에서 볼 수 있고, 세트는 같은 아이의 기기끼리 맞춰집니다. 보호자가 **오늘의 단어**를 켜면 매일 아이 수준에 맞는 단어가 아이 홈에 도착합니다.

## 아이가 쓰는 방법

1. **홈**에서 학습할 세트를 고르고, 시험 방식(읽기 + 뜻 / 영어 → 한글 / 한글 → 영어)과 범위(전체 또는 10단어씩, 책 번호 기준)를 고른 뒤 **▶ 시작!**
2. **시험 화면**
   - 읽기 + 뜻: ① 마이크로 영어 단어 읽기(음성이 안 되면 ‘✓ 소리 내어 읽었어요’) → ② 한국어 뜻 말하기/입력 → 정답 확인 → 다음. 뜻은 맞았는데 읽기가 ✕이면 그대로 넘어갈 때 오답으로 기록된다고 안내합니다.
   - 영어 → 한글: 뜻을 말하거나 입력 → 정답 확인.
   - 한글 → 영어: 알파벳으로 철자 말하기(C, A, T → cat) 또는 키보드·S펜으로 쓰기 → 정답 확인. 대소문자는 상관없습니다.
   - 모르면 **모름 · 정답 보기**. 오답으로 기록되고 복습에 들어갑니다.
   - 위쪽 **⏸ 쉬기**: 지금까지의 진행을 저장하고 홈으로 갑니다. 홈의 **▶ 이어서 하기**로 그 자리부터 다시 시작합니다. 탭을 닫거나 화면이 꺼져도 유지됩니다.
   - 위쪽 **그만하기**: 시험을 끝냅니다. 푼 문제가 있으면 ‘여기까지 N문제’ 결과 화면이 나오고 ‘중단’ 기록으로 저장됩니다. 쉬어 둔 시험을 지우거나 새로 시작할 때도 같은 규칙으로 기록이 남습니다.
3. **결과 화면**: 점수, 실제로 푼 시간(쉰 시간 제외), 틀린 단어 목록. **틀린 단어 다시 풀기**(방금 틀린 단어만), **같은 범위 다시**, **홈으로**.
4. 홈의 **틀린 단어 다시 풀기**는 그 세트에서 최근에 틀린 단어만 모아 냅니다. 마지막에 고른 세트·방식·범위·섞기는 다음에 열 때 그대로입니다.

### 음성 인식이 안 될 때
- 시험 화면의 입력칸을 터치하고 **휴대폰 키보드의 🎤**로 말하면 앱이 채점합니다. 키보드의 🎤는 앱의 파란 마이크 버튼과 다른 기능입니다.
- 설정 → **마이크·음성 인식 점검**에서 ① 권한 요청 → ② 음성 인식 시험 순서로 확인하세요. 권한은 사용자가 직접 허용해야 하며, 권한 허용과 음성 인식 서비스의 작동 여부는 별개입니다.
- 다운로드한 파일(`file://`)이나 앱 안 미리보기가 아니라 **HTTPS 주소를 Chrome에서 직접** 열어야 음성 인식이 됩니다.
- 음성은 브라우저 제공업체의 서버에서 처리될 수 있습니다. 앱 자체는 음성을 저장하거나 업로드하지 않습니다. 영어 읽기 판정은 인식된 텍스트 비교이며 전문 발음 평가가 아닙니다.
- 갤럭시 S펜: 삼성 키보드의 손글씨 모드(없으면 ⋯ → 손글씨)로 입력칸에 바로 쓸 수 있습니다. 한글 → 영어 시험은 키보드 언어를 English로 바꾸세요. 손글씨 인식은 기기가 처리하며 지원 여부는 기기·One UI 버전에 따라 다릅니다.

## 종합 시험 (여러 세트 묶어 보기)

- 세트가 두 개 이상이면 홈의 세트 카드 아래에 **📝 종합 시험**이 생깁니다. 펼쳐서 묶을 세트를 체크하고(기본은 전체), **문제 수**(10·20·30·50·전부)와 **뽑는 방법**(무작위 / 틀린 단어 먼저 / 세트별 골고루)을 고른 뒤 `▶ 종합 시험 시작`을 누르세요. 시험 방식과 순서 섞기는 아래 ‘어떻게 풀까요?’ 카드의 선택을 그대로 씁니다. 마지막 선택은 기억됩니다.
- ‘틀린 단어 먼저’는 고른 세트들의 오답 목록에 있는 단어부터 뽑고 모자라면 나머지에서 채웁니다. ‘세트별 골고루’는 세트를 번갈아 가며 뽑습니다.
- 기록은 **‘종합 시험 (세트 N개)’** 이름으로 남고 기록 탭의 ‘전체 세트’에서 보이며, 보호자 폰에도 같은 이름으로 올라갑니다. 틀린 단어는 **원래 속한 세트의 오답 목록**에 반영되어(맞힌 단어는 그 세트 오답에서 빠짐) 그 세트의 ‘틀린 단어 다시 풀기’와 ‘틀린 단어 먼저’ 뽑기로 이어집니다. 결과 화면의 ‘같은 범위 다시’는 같은 설정으로 다시 뽑습니다. 제한 시간·화면 이탈 기록·AI 2차 채점은 그대로 적용됩니다.

## 모르는 단어 찾기 (🔍 찾기 탭)

- 공부하다 모르는 영어 단어가 나오면 하단 **🔍 찾기** 탭에서 입력하거나 🎙 영어로 말해 찾습니다. 가족용 AI 서버의 사전(Claude)이 **뜻(품사) · 발음 기호 · 🔊 발음 듣기 · 예문 2~3개(영어 + 해석) · 비슷한 말**을 보여 줍니다. 철자가 틀렸으면 “혹시 ‘receive’인가요?”처럼 제안해 입력칸에 넣어 줍니다. 네이버 사전 같은 외부 사이트로 나가지 않습니다.
- 찾은 단어는 **‘찾아본 단어’ 세트에 자동으로 들어갑니다**(번호는 찾은 순서, 뜻·발음·허용 답안은 AI 결과). 보통 세트라서 홈의 세트 목록에 보이고 세 가지 시험 방식과 틀린 단어 복습이 그대로 되며, 가족 기록함에 연결된 기기라면 같은 아이의 다른 기기와 보호자 폰 📚 세트에도 올라갑니다. 찾기 탭의 **이 단어들로 시험 보기**를 누르면 그 세트가 골라진 홈으로 갑니다.
- 찾기 탭 아래 **📒 찾아본 단어**에는 언제, 몇 번 찾았는지와 예문이 남습니다(이 기기에만 저장). 같은 단어를 다시 찾으면 AI를 부르지 않고 저장된 결과를 보여 주며 횟수만 올라갑니다. 시험 중에는 찾기 탭이 숨어 쓸 수 없습니다. AI 연결(접속 코드)이 없는 기기에서는 쓸 수 없습니다.

### 📷 문제 물어보기 (AI 선생님)

- 찾기 탭의 **📷 문제 물어보기**에서 문제지(독해 지문·어법·배열·요지 고르기 등) 사진을 찍거나 고르고 **풀이 설명 · 해석해 줘 · 어법 설명 · 내 답 확인** 중 하나를 누르거나 **직접 질문**(예: “3번이 왜 3번이에요?”)을 적은 뒤 `물어보기`를 누르면 AI 선생님이 쉬운 한국어로 설명합니다. 답변은 **요약 → 해석 → 풀이(단계) → 기억할 포인트 → 내가 쓴 답 확인 → 정답** 순서이고, **정답은 접혀 있어** 먼저 생각하고 ‘정답 보기’를 열도록 되어 있습니다. 사진에 표시한 답(✓, 적은 답)이 있으면 맞는지 짚어 줍니다.
- 지문에서 어려운 단어 5~8개를 **모르는 단어 후보**로 보여 주고, 누르면 ‘찾아본 단어’ 세트에 들어가 시험으로 이어집니다. 물어본 문제는 **📒 물어본 문제**에 남아 다시 볼 수 있습니다(이 기기에만, 최근 100개).
- 가족 기록함에 연결된 기기에서는 **어떤 문제를 무엇 때문에 물었는지 요약만** 가족 서버로 가서 보호자 폰의 아이 상세 **📷 물어본 문제**에 보입니다. 사진은 읽는 동안만 전송되고 어디에도 저장되지 않습니다. 사진 한 장에 질문 하나, 120초 안에 답이 없으면 멈춥니다.

## 세트 만들기·관리 (보호자)

- 홈의 **➕ 새 세트 (사진)**: 세트 이름을 적고 사진(최대 10장, 각 10MB)을 고르거나 찍은 뒤 **✨ 사진에서 단어 가져오기**를 누릅니다. 촬영은 여러 번 눌러 여러 장을 쌓을 수 있고, 썸네일의 ✕로 뺄 수 있습니다. 이미 표에 있는 영어 단어는 다시 가져와도 건너뜁니다. 사진은 한 장씩 순서대로 가족용 AI 서버를 거쳐 Claude가 읽고 **번호 / 영어 / 뜻 / 허용 답안 / 발음**이 정리된 표를 채웁니다. 인쇄된 번호가 있으면 그대로 쓰고, 없거나 겹치면 이어서 번호를 매깁니다.
- **영어 단어만 있는 사진**(단어 목록·시험지·손으로 적은 목록)도 됩니다. 뜻이 인쇄되어 있지 않은 단어는 AI가 학습자 사전처럼 뜻·발음·허용 답안을 채우고 표에서 **노란 칸**으로 표시합니다. 사진에 뜻이 인쇄된 단어는 인쇄된 뜻만 쓰므로 책의 뜻과 AI가 채운 뜻이 섞이지 않습니다. 노란 칸은 틀릴 수 있으니 사전과 비교해 확인하세요.
- **✨ 빈 뜻 AI로 채우기**: 표나 텍스트에 영어만 적어 두고(텍스트 모드에서는 한 줄에 `apple`처럼) 누르면, 뜻이 빈 단어는 뜻·허용 답안·발음을, 발음만 빈 단어는 발음을 AI 사전에서 채웁니다. 이미 적힌 칸은 바꾸지 않고, 채운 칸은 노란색으로 표시되며 직접 고치면 표시가 사라집니다. 한 번에 40단어씩 순서대로 보내고, 못 찾은 단어(철자 오류 등)는 상태 문구로 알려 줍니다.
- **단어 표**에서 바로 고치고, **＋ 단어 추가**·행 삭제(✕)를 할 수 있습니다. ‘다른 정답’ 칸은 쉼표로 구분합니다. 많은 단어를 한 번에 붙여 넣으려면 **텍스트로 편집**(한 줄에 번호·영어·뜻·다른 정답·발음을 탭으로 구분, 다른 정답은 `|`로 구분, `apple 사과`처럼 입력해도 됨). 300단어가 넘으면 텍스트 모드로 표시됩니다. 저장할 때 문제가 있는 줄 번호를 알려 줍니다.
- 예문·표·다단은 잘못 읽히거나 빠질 수 있으니 **책과 비교해서 확인했어요**를 체크한 뒤 **저장**합니다. 시험은 자동 시작되지 않습니다. 발음은 책에 인쇄된 기호만 넣으며 비워 두어도 됩니다.
- **단어 보기·수정**: 저장된 세트를 표에서 고칩니다. 편집 중 설정에 다녀오거나 뒤로 가기를 눌러도 홈의 **편집 중인 세트로 돌아가기**로 이어지고, 저장하지 않은 단어가 있으면 닫기 전에 확인합니다.
- 편집 화면 아래 **이 세트 관리 (보호자)**: **✏️ 이름 바꾸기**(선택 목록과 기록에도 반영), **🗑 세트 삭제**(세트는 지워져도 시험 기록은 남음. 마지막 세트도 지울 수 있고, 세트가 없으면 홈에 ‘아직 세트가 없어요’가 보입니다). 아이가 쓰는 홈 화면에는 삭제 버튼이 없습니다. 가족 기록함에 연결된 기기에서는 세트를 만들거나 고치거나 지우면 같은 아이의 다른 기기와 보호자 폰에도 반영됩니다(아래 ‘세트는 아이 단위로 같아집니다’).
- **🔒 아이 기기에서 세트 고치기 잠금**: 보호자 앱의 아이 화면 → 📚 세트 탭에서 잠그면, 그 아이의 기기에서는 **➕ 새 세트**가 사라지고 **📖 단어 보기**로 단어를 보기만 합니다(이름·표가 읽기 전용이고 저장·사진·AI 채우기·단어 추가·삭제·이름 바꾸기·JSON 가져오기가 없습니다). 찾기 탭의 ‘찾아본 단어’ 세트와 AI 2차 채점이 인정한 허용 답안은 잠겨 있어도 계속 쌓입니다. 아이 기기가 다음에 앱을 열 때부터 적용되고, 풀면 다시 고칠 수 있습니다.
- 뜻 채점은 세 단계입니다. ① 대표 뜻 또는 허용 답안과 일치(공백·문장부호·“~입니다” 같은 끝말, 책의 ‘…을/…에게’ 같은 자리표시 조사와 괄호 설명은 무시) ② 뜻으로 끝나는 짧은 합성어 인정(‘무게’에 ‘몸무게’) ③ 그래도 다르면 **AI 2차 채점**: AI 서버가 설정된 기기에서는 틀린 답에 한해 AI에게 “같은 뜻인가”를 물어(동의어·조사/어미 차이·합성어는 인정, 다른 뜻·막연한 답·여러 뜻 나열은 거절) 인정되면 정답으로 처리하고 ‘AI 판정: …’ 이유를 보여 줍니다. 인정된 답은 그 단어의 허용 답안에 자동으로 추가되어 다음부터는 바로 정답이 되고(같은 아이의 다른 기기에도 동기화), 기록에는 ‘🤖 AI 인정 N개’로 남아 보호자 폰에서도 보입니다. 인터넷이 없거나 AI가 답하지 못하면 기기 채점 결과(오답)를 그대로 씁니다. 영어 스펠링 채점에는 AI를 쓰지 않습니다.

## 기록

- 기록 탭에서 세트별 시험 기록을 보고 **CSV 내려받기**를 할 수 있습니다. 각 기록에서 틀린 단어를 펼쳐 **이 시험의 틀린 단어 다시 풀기**가 됩니다. 삭제한 세트의 기록은 ‘전체 세트’에서 계속 보이며 당시 단어로 복습합니다. 기록 전체 삭제는 설정 → 백업에 있습니다(가족 기록함에 연결된 기기는 보호자에게 보낸 서버 사본이 남아 다시 가져올 수 있습니다).
- 점수는 정답 수 / 문제 수 × 100을 반올림합니다. 모름과 제한 시간 초과는 오답에 포함됩니다. ‘중단’ 기록은 그만하기까지 푼 문제만 담깁니다. 문제를 푸는 동안(채점 전) 앱이 1초 넘게 가려지거나 다른 앱으로 나가면 ‘⚠️ 화면 이탈 N회’가 기록에 남고 보호자 폰에도 표시됩니다(마이크 권한 창은 세지 않음).
- 기록은 같은 기기·브라우저에 저장됩니다. 브라우저 데이터를 지우면 기록도 없어지므로 설정 → 백업을 이용하세요.
- **기록 복원**(가족 기록함에 연결된 기기): 새 기기나 다시 설치한 앱은 기록이 비어 있으므로, 아이 코드로 연결하면 보호자에게 보냈던 기록(점수·틀린 단어)을 서버에서 가져와 기록 탭을 채웁니다. 가져온 기록은 ‘☁️ 서버에서 복원’으로 표시되고 점수·세트·방식·범위·틀린 단어가 보이며 **이 시험의 틀린 단어 다시 풀기**도 됩니다(단어별 전체 답안은 서버에 없어 정답 단어 목록은 없습니다). 이미 있는 기록은 겹치지 않고, 복원한 기록은 다시 서버로 보내지 않습니다. 기록 전체 삭제 뒤에는 자동으로 되살리지 않으며 설정 → 가족 기록함의 **☁️ 서버 기록 다시 가져오기**로만 가져옵니다(상태 줄에 ‘기록 N개 복원’).

## 보호자 폰에서 아이들 기록 보기 (보호자 앱 · 가족 기록함)

아이들은 각자 폰·태블릿에서 자기 단어장을 쓰고, 보호자는 자기 폰의 **보호자 앱**에서 선생님처럼 “오늘 시험을 봤는지, 점수는 어떤지”를 봅니다. 기록은 가족용 AI 서버(Cloudflare Worker)에만 저장되며 다른 서비스로 가지 않습니다. 2026-10-18 이전에 배포한 Worker는 `worker/README.md`대로 다시 배포하고 **보호자 코드**를 등록해야 합니다.

**1. 보호자 폰: 보호자 앱 설치하고 아이 만들기**
1. 보호자 폰에서 https://hongtaehwa.github.io/daily-vocab/parent.html 을 열어 홈 화면에 추가하면 **‘영단어 보호자’** 아이콘으로 설치됩니다(아이폰: Safari 공유(⬆) → 홈 화면에 추가, 갤럭시: Chrome 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치). 보호자 앱은 아이용 앱과 페이지·저장 공간이 따로이고 시험 화면 코드를 싣지 않아 가볍습니다. 처음 열면 **보호자 코드**(Worker 비밀값 `PARENT_PASSCODE`)를 묻고, 서버에 맞는 코드인지 확인한 뒤에만 저장합니다. 아이폰은 Safari와 홈 화면 앱의 저장 공간이 달라 **설치한 앱에서** 코드를 넣어야 합니다. 보호자는 갤럭시용 APK를 설치할 필요가 없습니다(APK는 시험을 푸는 아이 태블릿용).
2. 예전 보호자 아이콘(`…/?mode=parent`)이나 아이용 앱 설정에 보호자 코드를 넣어 두었던 폰은 그 아이콘·주소를 열면 **자동으로 보호자 앱으로 옮겨지고**, 보호자 코드·서버 주소·마지막으로 불러온 목록도 그대로 가져옵니다(다시 입력할 필요 없음). 보호자 폰에서 아이용 화면을 보려면 보호자 앱 ⚙️ 설정의 `아이용 앱 열기`를 누르세요(예전의 ‘아이 기기처럼 보기’는 없어졌습니다).
3. 하단 탭은 **🏠 오늘 · 🧒 아이들 · ⚙️ 설정** 세 개입니다. **🧒 아이들 → ➕ 아이 추가**에 이름을 적으면 6자리 **아이 코드**와 **아이 전용 링크**(`…/daily-vocab/?child=483921`)가 생기고, 바로 그 아이 화면의 **🔗 설정** 탭이 열려 `링크 복사`·`코드 복사`로 카톡 등으로 보낼 수 있습니다. 아이마다 한 번만 만듭니다.

**2. 아이 기기 연결 (아이폰·태블릿 모두, 기기마다 한 번)**
- 갤럭시 태블릿(Chrome): 받은 링크를 열면 그 아이로 바로 연결됩니다. 접속 코드가 아직 없으면 설정 화면이 열리고 코드가 채워져 있으니 `보호자 설정 · AI 연결`에 가족 접속 코드를 저장하면 그 자리에서 연결됩니다. 그 뒤 Chrome 메뉴 → 홈 화면에 추가.
- 아이폰: 먼저 Safari에서 주소를 열어 공유 → **홈 화면에 추가**로 설치한 뒤, **설치한 앱을 열어** 설정 → `보호자 설정 · AI 연결`에 접속 코드 저장 → `가족 기록함`에 아이 코드 6자리 입력 → `연결`. iOS는 Safari와 홈 화면 앱의 저장 공간이 달라 Safari에서 링크로 연결한 내용이 설치한 앱으로 넘어가지 않습니다.
- 같은 아이의 아이폰과 태블릿에 **같은 코드**를 넣으면 한 아이로 묶여 기록이 한곳에 모이고 오늘의 단어도 같은 것을 받습니다. 연결되는 순간 그 기기의 지금까지 기록도 함께 올라가고, 이후 시험을 마칠 때마다(쉬기 후 이어서 끝낸 시험, 그만하기로 끝낸 ‘중단’ 포함) 자동으로 보냅니다.
- 연결되면 반대로 서버에 있던 **이 아이의 기록도 이 기기로 들어옵니다**(다른 기기에서 본 시험, 다시 설치하기 전 기록). 기록 탭에 ‘☁️ 서버에서 복원’으로 표시되며 점수·틀린 단어까지 있고 다시 풀기도 됩니다. 자세한 내용은 위 ‘기록’ 절.
- 인터넷이 안 될 때 끝낸 시험은 ‘못 보낸 기록 N개’로 남았다가 다음에 앱을 열거나 화면으로 돌아올 때 다시 보냅니다. 보내는 내용은 세트 이름·단어 수, 시험 방식·범위, 점수, 푼 시간, 틀린 단어(영어·뜻), 기기 종류이며 단어별 전체 답안이나 세트 단어는 보내지 않습니다. `연결 해제`를 누르면 그 기기만 빠집니다.
- 아이용 앱에는 보호자 코드 칸도 보호자 화면도 없어 아이 기기에서는 형제의 기록을 볼 수 없습니다.

**3. 보호자 앱에서 보기**
- **🏠 오늘**: 아이마다 카드 한 장 — ‘오늘 시험 ✅ 2회 · 평균 80점’(또는 ‘오늘 시험 아직’), 🔥 연속 학습일, 오늘의 단어 상태(‘오늘의 단어 ✅ 9 / 10’ · 도착 · 아직 없음 · 꺼짐), ‘⚠️ 오늘 화면 이탈 N회’ · ‘⏱ 시간 초과 N개’, ‘📷 물어본 문제 N개’, 최근 7일 칸(요일별 평균 점수), ‘이번 주 N회 · 평균’과 지난주 비교(▲▼), 마지막 시험. 아직 기기가 연결되지 않은 아이는 아이 코드와 `링크 복사`만 보입니다. 카드를 누르면 그 아이 화면으로 갑니다.
- **아이 화면**은 하위 탭 다섯 개입니다. 안드로이드 뒤로 버튼·`← 뒤로`는 화면 단위로 돌아갑니다(하위 탭을 바꾼 것은 뒤로 가기에 쌓이지 않음).
  - **🕒 기록**: 이번 주·지난주·최근 30일 평균·연속 학습 요약, **📉 자주 틀린 단어**(최근 2주 상위 10개, 틀린 횟수와 뜻), 세트·기간(최근 7일 / 30일 / 전체) 필터, 날짜별로 묶은 기록(점수·방식·범위·푼 시간·중단·📬 오늘의 단어·⏱ 시간 초과·🤖 AI 인정·⚠️ 화면 이탈, 틀린 단어 펼치기). 처음에는 최근 30일 기록(많으면 최근 200개)을 받고 ‘전체 N회 중 최근 N개를 받았어요’로 알려 줍니다. 맨 아래 **⬇ 이전 기록 더 보기**를 누르면 기간이 ‘전체’로 바뀌고 그 이전 기록을 100개씩 더 받습니다(이 폰에 저장하지는 않아서 앱을 다시 열면 다시 눌러야 합니다).
  - **복습 세트 보내기**: 📉 자주 틀린 단어의 단어를 눌러 빼거나 넣고(처음에는 전부 골라져 있음) **📚 이 단어들로 복습 세트 보내기**를 누르면 ‘복습 10/19’ 같은 이름의 세트가 그 아이의 모든 기기로 갑니다(같은 이름이 있으면 ‘복습 10/19 (2)’). 뜻은 시험 기록에 남은 뜻을 쓰고, 뜻이 기록되지 않은 단어는 빼고 알려 줍니다. 보내면 📚 세트 탭으로 옮겨 가 새 세트가 보입니다.
  - **📚 세트**: 그 아이의 세트(단어 수 · 최근 점수 · 30일 시험 횟수 · 고친 때), 보기·수정, 삭제, ➕ 세트 만들어 보내기, 🔒 세트 고치기 잠금(아래 4).
  - **📬 오늘의 단어**: 수준 제안 카드, 켜기·수준·하루 단어 수·만드는 시각, 오늘 것 지금 만들기, 수준 기준 세트, 오늘 것 미리보기와 **📚 세트로 저장해 보내기**(아래 ‘오늘의 단어’).
  - **🔗 설정**: 아이 코드·전용 링크·복사·코드 새로 만들기(옛 코드와 옛 링크는 무효)·연결된 기기, 이름 바꾸기, **⏱ 문제당 제한 시간**(바꾸는 즉시 저장), **🗑 서버에서 삭제**(아이 이름을 그대로 적어야 지워짐).
  - **📷 질문**: 아이가 AI 선생님에게 물어본 문제의 요약·질문·시각과 ‘이번 주 N개’.
- ‘오늘’과 ‘이번 주’는 보호자 폰의 날짜 기준입니다. 마지막으로 불러온 내용은 폰에 남아 인터넷이 없어도 직전 상태가 보이고(위쪽에 ‘마지막 확인 N분 전’), 앱을 열 때·화면으로 돌아올 때·인터넷이 돌아올 때 10분이 지났으면 새로 불러옵니다. 위쪽 🔄로 바로 다시 불러옵니다. 저장·전송 결과는 아래쪽 알림과 그 칸 아래 문구로 알려 줍니다.
- 기기를 바꾸거나 앱을 다시 설치했으면 새 기기에 같은 코드를 넣으면 됩니다. 세트와 함께 서버에 있는 기록(점수·틀린 단어)도 그 기기의 기록 탭에 돌아옵니다. 아이를 지우면 기록·코드·세트가 모두 지워지고, 연결돼 있던 아이 기기는 설정 → 가족 기록함에 ‘보호자가 이 아이를 서버에서 지웠어요’ 안내가 뜨면서 기록·세트 보내기를 멈춥니다(아이 기기의 기록과 세트는 그대로). 그 기기에서 `연결 해제`를 누르고 새로 만든 아이의 코드로 다시 연결하면 그동안의 기록도 함께 올라갑니다.
- **이전 기록 더 보기·복습 세트·수준 제안(2026-10-19)**: 보호자가 Worker를 다시 배포해야(`cd worker && npm run deploy`) ‘이전 기록 더 보기’와 정확한 전체 시험 횟수가 동작합니다. 다시 배포하기 전에는 보호자 앱이 아이마다 최근 200개만 보여 주고 ‘더 보기’ 버튼이 나오지 않을 뿐 다른 기능(복습 세트 보내기·오늘의 단어 세트로 저장·수준 제안 포함)은 그대로 됩니다.
- **⚙️ 설정**: 보호자 코드 상태·코드 바꾸기·**보호자 코드 삭제**(이 폰에 저장한 아이들 기록 캐시도 함께 지우고 코드 입력 화면으로; 서버 기록은 그대로), 고급: 서버 주소, 🔔 알림(준비 중), 설치 안내·아이용 앱 열기, 앱 정보(버전·새 버전 불러오기·앱 점검).

**4. 세트는 아이 단위로 같아집니다 (세트 동기화)**
- 아이 코드로 연결된 기기는 앱을 열 때·화면으로 돌아올 때·세트를 저장/이름 바꾸기/삭제/가져오기 한 뒤에 세트를 가족용 AI 서버의 **그 아이 항목**과 맞춥니다. 같은 아이의 아이폰과 태블릿이 항상 같은 세트를 보고, 한쪽에서 고치면 다른 쪽은 다음에 앱을 열 때 바뀝니다(세트마다 더 나중에 고친 쪽이 남고, 지운 세트는 다른 기기에서도 사라집니다). 시험 기록·오답은 전처럼 기기마다 따로이고, 설정의 가족 기록함에 ‘세트 N개 · 보호자·다른 기기와 같은 세트’로 상태가 보입니다. 시험 중에는 세트를 바꾸지 않고, 시험 중에 AI 2차 채점이 인정한 답이 허용 답안에 들어가 세트가 바뀌면 시험을 마치거나 그만두는 즉시 올립니다.
- 연결하면 손대지 않은 **기본 예제 세트는 그 기기에서 사라지고**, 아이의 세트가 아직 없으면 홈에 ‘아직 세트가 없어요’가 보입니다. 그래서 형제가 같은 예제 세트를 보는 일이 없습니다. 예전에 다른 브라우저(Chrome·Safari)에서 만든 세트는 그 브라우저를 열어 같은 아이 코드로 연결하면 올라가고, 설치한 앱에도 들어옵니다(JSON 백업을 옮길 필요가 없습니다).
- 보호자 앱: 아이 화면의 **📚 세트** 탭에 그 아이의 세트가 보이고, **➕ 세트 만들어 보내기 (사진)**으로 교재 사진에서 세트를 만들어 바로 아이에게 넣어 줄 수 있습니다(편집 화면은 아이용과 같고 사진 인식·빈 뜻 채우기는 보호자 코드로 동작합니다. 저장을 누르면 보호자 폰에 남지 않고 아이에게 갑니다. 저장하지 않고 뒤로 가면 먼저 물어봅니다). **보기·수정**으로 단어를 고쳐 다시 보내고, **삭제**하면 아이의 모든 기기에서 사라집니다. 아이 기기에는 다음에 앱을 열 때(또는 화면으로 돌아올 때) 들어갑니다.
- 보호자 앱: 📚 세트 탭의 **🔒 아이 기기에서 세트 고치기 잠금**을 켜면 아이 기기에서는 세트를 만들거나 고치거나 지울 수 없고 단어를 보기만 합니다(바꾸는 즉시 저장되고, 아이 기기가 다음에 앱을 열 때부터 적용). 아이가 뜻이나 허용 답안을 고쳐 시험을 쉽게 만들거나 실수로 세트를 지우는 일을 막습니다. 찾아본 단어 세트와 AI가 인정한 답은 그대로 쌓입니다.
- 한도: 아이당 세트 50개, 세트당 단어 2,000개. 2026-10-18 이전 Worker에는 이 기능이 없어 설정의 가족 기록함에 ‘세트를 맞추지 못했어요’가 보이고 예제 세트가 그대로 남습니다. Worker를 다시 배포하면 됩니다.

## 오늘의 단어 (매일 자동 퀴즈)

보호자가 아이별로 켜 두면 매일 정한 시각에 가족용 AI 서버가 아이 수준에 맞는 단어를 만들어 아이 홈에 **📬 오늘의 단어** 카드로 보여 줍니다. 단어는 웹에서 가져오지 않고 Claude가 만들며, 아이의 최근 세트(학원 교재 사진으로 만든 세트)의 단어를 “지금 이 수준을 공부한다”는 기준으로 함께 보내 비슷하거나 한 단계 위 단어를 고르게 합니다. 가족 기록함(위 절)이 먼저 켜져 있어야 합니다.

- **하루 구성**: 기본 10개 = 복습 최대 3개(최근 14일에 틀린 단어) + 새 단어. 같은 단어는 다시 내지 않습니다(아이별로 이미 낸 단어를 서버가 기억).
- **보호자 앱**: 아이 화면의 **📬 오늘의 단어** 탭에서 켜기, 수준(초등 고학년 상위권 / 중1 / 중2 상위권 / 중3·고1 / 고1·수능 기초 / 고2·수능 실전 / 직접 입력), 하루 단어 수(5·10·15·20), 만드는 시각을 정하고 `저장`. `오늘 것 지금 만들기`로 바로 만들어 미리 볼 수 있습니다(복습 단어에는 ‘복습’ 표시). 🏠 오늘 카드에 ‘오늘의 단어 ✅ 9 / 10’, ‘📬 도착 · 아직 안 풀었어요’, ‘아직 없음’, ‘꺼짐’이 표시됩니다. 문제당 제한 시간은 오늘의 단어와 무관하게 모든 시험에 적용되므로 🔗 설정 탭에 있습니다.
- **아이 기기**: 앱을 열면 카드가 뜨고 `▶ 풀기`를 누르면 평소 시험과 같은 화면(고른 시험 방식 그대로)으로 풀어요. 끝나면 ‘✅ 오늘의 단어 끝! 9 / 10’으로 바뀌고 틀린 단어는 내일 복습에 나옵니다. 정한 시각 전에 앱을 열거나 첫날이면 그 자리에서 바로 만듭니다(10초쯤). 그만하기로 끝낸 ‘중단’은 완료로 치지 않습니다.
- 오늘의 단어는 세트 목록에 쌓이지 않습니다. 지난 날 단어는 기록(틀린 단어)과 서버에 남습니다. 다시 공부시키고 싶으면 보호자 앱의 오늘 것 미리보기 아래 **📚 세트로 저장해 보내기**를 누르세요. ‘오늘의 단어 10/19’ 이름의 세트로 아이의 모든 기기에 들어갑니다(오늘의 단어 시험 기록과는 따로입니다).
- **수준 제안**: 📬 오늘의 단어 탭 위쪽에 최근 2주 점수를 보고 제안 카드가 뜹니다. 이번 주와 지난주 모두 시험 3회 이상·평균 90점 이상이고 최근 2주 틀린 단어가 5개 이하면 “최근 2주 평균 92점이에요. 수준을 ‘중3·고1’로 올려 볼까요?”, 두 주 평균이 모두 60점 미만이면 한 단계 낮추자고 합니다. 앱은 제안만 하고 바꾸지 않습니다. `적용`을 누르면 수준만 바뀌고(켜고 끄기·개수·시각은 그대로, 꺼져 있으면 꺼진 채로), `다음에`를 누르거나 적용한 뒤에는 일주일 동안 다시 묻지 않습니다. 직접 입력한 수준이거나 더 올릴(내릴) 단계가 없으면 카드가 뜨지 않습니다.
- 수준은 AI가 고르므로 학원 시험 범위와 다를 수 있습니다. 너무 쉽거나 어려우면 수준을 바꾸세요(위 수준 제안 참고). 생성 모델은 `worker/wrangler.jsonc`의 `DAILY_MODEL`(기본 `claude-sonnet-5-5`, 하루 아이당 1원 미만)입니다.

## AI 서버 설정 (보호자용)

AI 인식은 보호자가 한 번 만들어 두는 **가족용 AI 서버**(Cloudflare Worker, 무료 플랜)를 통해 동작합니다. Anthropic API 키는 그 서버의 비밀값에만 있고 앱·저장소·태블릿 어디에도 들어가지 않습니다. 서버를 만드는 방법은 [worker/README.md](worker/README.md)에 있습니다(약 5분).

1. `worker/README.md`대로 배포하고 가족용 **접속 코드**를 정합니다.
2. 태블릿에서 앱의 설정 탭 → `🔒 보호자 설정 · AI 연결`을 펼칩니다. 서버 주소는 기본값(`https://daily-vocab-ai.reonwipe.workers.dev`)이 들어 있으므로 접속 코드만 입력 → `저장` → `연결 확인`.
3. 이후 아이는 사진을 올리고 `사진에서 단어 가져오기`만 누르면 됩니다. 영어만 적은 단어는 `빈 뜻 AI로 채우기`로 뜻을 채웁니다(2026-10-18 이전에 배포한 Worker는 `npm run deploy`로 다시 배포해야 이 기능이 동작합니다).

모델은 서버 설정(`CLAUDE_MODEL`)에서 고릅니다: `claude-opus-5-5`(기본, 가장 정확), `claude-sonnet-5-5`(빠름), `claude-haiku-5-5`(가장 저렴). 사진 한 장당 대략 Opus 0.05달러, Sonnet 0.02달러, Haiku 0.002달러 수준이고, 빈 뜻 채우기 한 번(최대 40단어)은 사진 한 장과 비슷하거나 더 적습니다. Anthropic 콘솔에서 **월 사용 한도**를 꼭 설정하세요.

**보안·개인정보**

- 태블릿에는 서버 주소와 접속 코드만 저장됩니다(백업 JSON·CSV에 포함되지 않음). 기기를 잃어버리면 접속 코드를 바꾸면 됩니다.
- 서버는 허용된 앱 주소(Origin)와 접속 코드가 맞는 요청만 처리하고 IP당 요청 수를 제한합니다. 피해 범위는 Anthropic 콘솔의 사용 한도로 다시 제한됩니다.
- AI 인식을 쓰면 사진(긴 변 2000픽셀 이하 JPEG)이 서버를 거쳐 Anthropic에 전송되어 처리됩니다. ‘빈 뜻 AI로 채우기’를 쓰면 표에 적힌 영어 단어 중 뜻이나 발음이 빈 것만, ‘단어 찾기’는 찾는 단어만, ‘문제 물어보기’는 문제지 사진과 질문 문장이 같은 경로로 전송됩니다. 문제 물어보기의 사진은 저장되지 않으며, 가족 기록함에 연결된 기기에서는 문제 요약·질문·시각만 가족 서버에 남아 보호자가 봅니다. Anthropic은 API로 받은 이미지를 요청 처리 후 보관하지 않고 모델 학습에 쓰지 않는다고 안내합니다. 개인정보가 담긴 사진은 올리지 마세요.
- 이전 버전(API 키를 태블릿에 저장하던 방식)을 쓰던 기기는 앱을 열면 저장된 키를 자동으로 지웁니다. 그 키는 Anthropic 콘솔에서 삭제하세요.
- **가족 기록함**에 연결하면 시험을 마칠 때마다 아이 번호(보호자가 만든 아이), 기기 종류(iPhone·Android 태블릿 등), 세트 이름·단어 수, 시험 방식·범위, 점수, 푼 시간, 틀린 단어(영어·뜻)가 가족용 AI 서버의 저장소(Cloudflare Durable Object)에 저장됩니다. 단어별 전체 답안·세트 단어·사진은 보내지 않습니다. 보호자 코드가 있는 폰만 읽을 수 있고, 아이 기기에는 가족 코드만 있어 형제의 기록을 볼 수 없습니다. 아이 이름·아이 코드·보호자 코드는 기기에만 저장되며 백업 JSON·CSV에 포함되지 않습니다. 아이 전용 링크에는 아이 코드만 들어 있고 접속 코드는 들어 있지 않습니다. 서버에 남은 기록은 보호자 앱의 아이 화면 → 🔗 설정 → **🗑 서버에서 삭제**로 지웁니다. 보호자 앱은 보호자 코드와 마지막으로 불러온 아이들 기록(캐시)을 그 폰에만 저장하고, 보호자 코드를 삭제하면 캐시도 함께 지웁니다.
- 가족 기록함에 연결된 기기는 기록을 보낼 때 최근 세트의 영어 단어(최대 60개, 뜻 제외)도 함께 보내 **오늘의 단어**의 수준 기준으로 씁니다. 손대지 않은 기본 예제 세트는 수준 기준으로 쓰지 않으며, 보낼 세트가 없으면 서버의 수준 기준을 비웁니다(보호자 앱 📬 오늘의 단어 탭에 ‘수준 기준 세트가 아직 없어요’). 오늘의 단어를 켜면 그 단어 목록과 최근 틀린 단어, 수준 문구가 Claude에 전송되어 새 단어를 만듭니다. 사진·세트 전체·아이 이름은 Claude에 보내지 않습니다.

## 부정행위 막기 (화면 번역·AI 검색)

갤럭시의 서클 투 서치(Circle to Search)·Gemini, 아이폰의 Apple Intelligence·Siri는 화면을 캡처해 읽기 때문에 시험 화면의 영어 단어를 바로 번역해 줄 수 있습니다. 웹 앱은 이런 OS 기능을 막을 수 없어 세 겹으로 대응합니다.

- **앱에서**: 시험 화면의 단어·뜻은 선택·복사·길게 누르기 메뉴가 막혀 ‘선택 → 번역’이 되지 않습니다. 문제를 푸는 동안 앱이 가려지거나 다른 앱으로 나가면 **화면 이탈**로 기록되어 보호자 폰의 기록에 ‘⚠️ 문제 중 화면 이탈 N회 · 총 M초’, 아이 카드에 ‘⚠️ 오늘 화면 이탈 N회’로 보입니다. 막지는 못하지만 바로 알 수 있습니다(서클 투 서치 호출이 이탈로 잡히는지는 기기마다 다를 수 있습니다).
- **문제당 제한 시간**: 보호자 앱의 아이 화면 → 🔗 설정 탭의 **⏱ 문제당 제한 시간**(없음 / 10·15·20·30·45·60초, 바꾸는 즉시 저장)을 정하면 그 아이의 **모든 시험**에 적용됩니다. 시험 화면 위에 남은 시간이 보이고, 시간이 지나면 그 문제는 자동으로 ‘모름’이 되어 정답이 보입니다. 앱 밖에 나가 검색하는 동안에도 시간은 흐릅니다. 기록에는 ‘⏱ 시간 초과 N개’로 남고 보호자 폰에도 표시됩니다. 아이 기기는 앱을 열 때 설정을 받아 가므로 바꾼 값은 다음에 앱을 열 때부터 적용됩니다.
- **기기 설정에서**: 갤럭시는 설정 → 디스플레이 → 내비게이션 바에서 서클 투 서치를 끄고, Gemini는 Google 앱의 어시스턴트 설정이나 Family Link로 끕니다. 시험 때만 앱 고정(화면 고정)을 쓸 수도 있습니다. 아이폰은 설정 → 스크린 타임 → 콘텐츠 및 개인 정보 보호 제한 → Intelligence 및 Siri를 끄고, 시험 때 사용 안내 모드(측면 버튼 세 번)를 켤 수 있습니다. 메뉴 이름은 기기·버전에 따라 다를 수 있습니다.
- **갤럭시 태블릿용 앱**: 이 웹앱을 감싼 안드로이드 앱은 화면 캡처 금지(FLAG_SECURE)를 걸어 이 앱 화면에서만 스크린샷·서클 투 서치가 동작하지 않게 하고, **화면 분할·팝업 화면**으로 열어 옆에 브라우저나 AI 앱을 띄우는 것도 막습니다(분할 중에는 안내 화면만 보이고 ‘화면 이탈’로 기록. 앱 v1.2, 아래 ‘갤럭시 태블릿용 앱’ 절). 아이폰은 앱이 스크린샷·Siri 화면 읽기를 막을 수 없어 스크린 타임 제한이 유일한 차단입니다.

## 백업·설치

- 설정 → **전체 백업 JSON**은 세트·시험 기록·틀린 단어를 함께 내보냅니다(서버에서 복원한 기록도 포함). **JSON 가져오기**는 새 세트로 복사하여 기존 세트를 보존합니다(복원한 기록은 같은 것이 이미 있으면 한 번만 둡니다). 저장 오류가 표시되면 JSON을 먼저 백업하세요. 손상된 저장 자료는 덮어쓰지 않습니다.
- Chrome 메뉴 → **홈 화면에 추가**로 앱처럼 설치할 수 있습니다. 앱 셸과 저장된 세트는 한 번 접속한 뒤 오프라인으로 사용할 수 있습니다. AI 사진 인식과 외부 음성 인식은 인터넷이 필요합니다. 새 버전 안내가 나오면 시험을 마치고 앱을 닫았다가 다시 엽니다.
- 보호자 폰에는 아이용 앱 대신 **보호자 앱**(https://hongtaehwa.github.io/daily-vocab/parent.html)을 홈 화면에 추가합니다(아이콘 ‘영단어 보호자’). 두 앱은 같은 오프라인 캐시를 써서 한 번 연 뒤에는 인터넷이 없어도 화면과 마지막으로 불러온 카드가 열립니다. 보호자 앱에 저장되는 것은 보호자 코드·서버 주소·마지막으로 불러온 아이들 기록(캐시)뿐이라 백업 JSON이 없습니다. 예전 보호자 아이콘(`…/?mode=parent`)은 열면 보호자 앱으로 자동으로 옮겨집니다.

## 갤럭시 태블릿용 앱 (서클 투 서치·스크린샷 차단)

갤럭시에서 홈 버튼을 길게 누르면 서클 투 서치가 화면의 영어 단어를 번역해 버리는 문제에 대한 답으로, 웹앱을 감싼 **안드로이드 앱**을 따로 제공합니다(`android/`). 이 앱은 자기 화면에 화면 캡처 금지(FLAG_SECURE)를 걸어 **이 앱 안에서만** 스크린샷·화면 녹화·서클 투 서치가 동작하지 않게 하고, 화면 분할·팝업 화면도 막습니다(v1.2: 분할 비지원 선언 + OS가 분할을 강제하면 분할 중에는 ‘화면 분할은 쓸 수 없어요’ 안내만 보이고 웹앱은 ‘화면 이탈’로 기록). 다른 앱에는 영향이 없고, 세트·기록·가족 기록함·오늘의 단어는 웹앱 그대로입니다. 음성 인식은 안드로이드 기본 음성 인식기(삼성/구글)를 씁니다. 설정의 **JSON 가져오기**에서 .json 파일을 고르려면 앱 v1.3 이상이 필요합니다(이전 버전은 파일 선택기가 사진만 보여 주었습니다). 설정의 **전체 백업 JSON**과 기록 탭의 **CSV 내려받기**는 앱 v1.4 이상에서 ‘다운로드’ 폴더에 저장됩니다(이전 버전은 눌러도 아무 일이 없었습니다).

- 설치: 태블릿에서 https://github.com/HongTaeHwa/daily-vocab/releases 의 최신 `android-vN` 릴리스에서 `daily-vocab-app-vN.apk`를 내려받아 설치합니다(‘알 수 없는 앱 설치’ 허용). 앱은 Chrome과 저장 공간이 다르므로 앱 안에서 접속 코드와 아이 코드를 다시 넣습니다. 자세한 설치·업데이트·서명 안내는 [android/README.md](android/README.md).
- 확인: 앱 화면에서 홈 버튼을 길게 눌러 서클 투 서치를 해 보면 “이 화면에서는 사용할 수 없음” 또는 검은 화면이 나와야 합니다.
- 아이폰은 iOS가 앱에 스크린샷·Siri 화면 읽기 차단 수단을 주지 않아 같은 앱을 만들 수 없습니다. 스크린 타임 → 콘텐츠 및 개인 정보 보호 제한 → Intelligence 및 Siri 끄기와 사용 안내 모드를 쓰세요.

## 배포

`main` 브랜치의 루트 디렉터리를 GitHub Pages 게시 소스로 사용합니다. 진입점은 `index.html`이며 빌드 단계가 없습니다. 사진 인식은 `worker/`의 Cloudflare Worker가 담당하며 별도로 배포합니다. 보호자 앱은 `parent.html`입니다. 앱 셸(`index.html`, `parent.html`, `shared.js`, `quiz.js`, `family.js`, `editor.js`, `sets.js`, `parent.js`, `parent.css`)을 바꿀 때는 두 페이지의 버전 문자열과 `sw.js`의 CACHE 버전을 함께 올립니다(`CLAUDE.md` 참고).

## 개발 및 브라우저 검증

앱은 빌드나 런타임 패키지 없이 정적 서버로 실행합니다. `node .claude/dev-server.cjs`가 저장소를 GitHub Pages와 같은 `/daily-vocab/` 경로(`http://127.0.0.1:8000/daily-vocab/`)로 제공합니다.

앱은 두 페이지입니다. 아이용 앱 `index.html`은 전역 스크립트 다섯 개를 이 순서로 불러옵니다: `shared.js`(공통 도우미·서버 요청) → `quiz.js`(화면 전환·시험·기록) → `family.js`(아이 기기의 가족 기록함·오늘의 단어·세트 동기화) → `editor.js`(세트 편집기) → `sets.js`(세트 저장·백업·AI 연결·찾기·문제 물어보기). 보호자 앱 `parent.html`(http://127.0.0.1:8000/daily-vocab/parent.html)은 `shared.js` → `editor.js` → `parent.js`(저장소·해시 라우터·화면)와 스타일 `parent.css`를 씁니다. 가족 서버 가짜 응답은 `tests/lib/fake-family-worker.cjs` 하나를 `family`·`daily`·`parent`·`parent-sets` 테스트가 함께 씁니다.

테스트는 전역 설치된 Playwright(`npm i -g playwright && npx playwright install chromium`)로 실행합니다. `node .claude/run-tests.cjs`가 서버를 자동으로 띄우고 아래를 모두 실행합니다. 개별 실행은 `CHROMIUM_PATH=/usr/bin/chromium node tests/browser.cjs`처럼 하며 기본 URL은 `APP_URL`로 바꿀 수 있습니다. 테스트는 별도의 브라우저 컨텍스트에서 실행하므로 실제 사용자 저장 자료에 영향을 주지 않습니다.

- `tests/worker.cjs` — Cloudflare Worker 프록시 단위 테스트(Node만 필요): CORS·접속 코드·요청 제한·입력 검증·결과 정리·AI가 채운 뜻 표시·AI 사전(`/define`)·Anthropic 오류 변환·북미 중계·가족 기록함(`/sync`·`/family`, 보호자 코드)·아이 코드(아이 만들기·`/join`·기기 목록·코드 새로 만들기)·오늘의 단어(`/daily`, 계획, 크론)·빈 앵커로 수준 기준 삭제·지운 아이의 `/sync` 404·보호자 상세의 최근 30일 창(`days`·`limit`·`recordCount`·`more`, 기록 5,000개 아이도 첫 응답 200개 이하)·‘더 보기’ 페이지(`/family/<id>/records?before=`)
- `tests/browser.cjs` — 기본 세트 40단어, 3가지 시험 방식, 세트 저장·백업 JSON 왕복, 세트별 기록, 구버전 이전
- `tests/session.cjs` — 탭 전환, 시험 글자 선택 차단, 쉬기 → 새로고침 → 이어서 하기, 그만하기(중단 기록), 이름 바꾸기, 단어 표 편집기, 마지막 선택 기억
- `tests/pwa.cjs` — 화면 폭·오프라인 셸·매니페스트(아이 앱과 보호자 앱 모든 화면의 768/1024/390 폭), AI 서버 오류 안내와 취소
- `tests/app-update.cjs` — 옛 스크립트 캐시 우회, 초기화 실패 표시, 갱신 시 저장 자료 보존, 보호자 앱 버전·자원 버전·앱 점검
- `tests/ten-photos.cjs` — 사진 10장 순차 처리와 결과 보존, 11장 거부
- `tests/ai-recognition.cjs` — 보호자 설정, 연결 확인, 사진 2장 인식과 번호 병합, AI가 채운 뜻의 노란 칸 표시, 저장·시험, 빈 뜻·발음 AI 채우기, 오류 안내, 취소 (AI 서버는 가짜 응답)
- `tests/family.cjs` — 가족 기록함 + 아이 코드(아이 기기): 아이용 앱에 보호자 화면 없음, 전용 링크로 열었을 때 접속 코드 대기 → 저장 뒤 자동 연결, 등록 전송(기기·세트·앵커), 문제 중 화면 이탈 1초 이상만 집계·전송, 시험 완료 후 전송 내용, 연결 실패 시 대기와 재시작 후 재전송, 끄기, 연결 해제 → 코드로 재연결(모르는 코드 안내), 기록 복원, 보호자가 보낸 세트 받기·기기에서 지우기·빈 상태, 시험 중 AI가 인정한 답을 학습하면 시험이 끝난 직후 세트 전송, 손대지 않은 예제는 수준 기준에서 제외, 보호자가 서버에서 지운 아이의 기기 안내·요청 중단·새 코드로 재연결 (가족 서버는 가짜 응답)
- `tests/daily.cjs` — 오늘의 단어(아이 기기): 계획이 꺼져 있으면 카드 없음(예제 세트뿐이면 빈 수준 기준), 켠 뒤 앱을 열면 생성 → 카드 → 풀기 → 기록에 날짜 표시 → ✅ 카드 → 새로고침 후 재생성 없음, 제한 시간 수신·카운트다운·시간 초과, 세트 잠금 수신·읽기 전용 편집기 (가족 서버는 가짜 응답)
- `tests/parent.cjs` — 보호자 앱: 코드 입력(짧은 코드·틀린 코드·옛 Worker), 코드 → 오늘 카드까지 요청 1회, 오늘 카드(연결된 아이·연결 안 된 아이), 해시 뒤로 가기, 아이 화면 하위 탭 5개(기록 요약·자주 틀린 단어·필터 / 세트·잠금 / 계획 저장·지금 만들기·끄기 / 코드·링크·기기·제한 시간·이름·코드 새로 만들기 / 질문), 아이 추가, 이름 확인 삭제, 오프라인 캐시, 코드 삭제, 옛 보호자 설치(`?mode=parent`) 자동 이동·코드 이전, 이전 기록 더 보기(페이지·옛 Worker), 틀린 단어로 복습 세트 보내기, 오늘의 단어 세트로 저장, 수준 제안(규칙·적용·다음에) (가족 서버는 가짜 응답)
- `tests/parent-sets.cjs` — 보호자 앱 세트 보내기: 편집기 제목 ‘…에게 보내기’, 사진 인식은 보호자 코드, 전송 본문·목록, 보호자 폰에 사본 없음, 보기·수정(단어 id·발음 유지), 저장하지 않은 초안 확인, 삭제, 편집기 주소로 바로 열기

실제 Anthropic 호출은 키가 필요해 자동 테스트에 없습니다. 실제 교재 사진의 인식 품질과 Android 태블릿의 설치·마이크·S펜·음성 철자 인식은 실기기 확인이 필요합니다. 사진 검증용 개인정보 자료를 공개 저장소에 커밋하지 마세요.

설정 → 앱 정보에 화면 버전과 초기화 상태가 표시됩니다. 화면이 이상하면 **새 버전 불러오기**를 누르세요. 저장한 자료는 유지되며 미저장 입력은 확인 후 초기화됩니다. **앱 점검**은 사진 수·가져오기 버튼 연결 상태·화면 처리 오류를 표시합니다. 설계 배경과 개편 내역은 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.
