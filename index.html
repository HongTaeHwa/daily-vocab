    🕒 시험 기록

    기록은 이 기기의 브라우저에 저장돼요. 브라우저 데이터를 지우면 기록도 사라지니 설정 → 백업을 이용하세요. 가족 기록함에 연결된 기기는 보호자에게 보낸 기록(점수·틀린 단어)을 서버에서 다시 가져올 수 있어요(‘☁️ 서버에서 복원’ 표시).

    👨‍👩‍👧 보호자 모드

    아이들의 시험 기록·오늘의 단어·제한 시간을 관리하는 화면이에요. 시작하려면 보호자 코드(Worker 비밀값 PARENT_PASSCODE)를 넣어 주세요. 아이 기기에는 넣지 마세요.

    아이를 만들면 6자리 아이 코드와 전용 링크가 생겨요. 아이 기기(아이폰·태블릿 모두)에서 그 코드를 넣거나 링크를 열면 같은 아이로 연결됩니다.

    아이 기기가 시험을 마칠 때마다 보낸 기록이에요. ‘오늘’과 ‘최근 7일’은 이 폰의 날짜 기준입니다.

    📚 세트

    여기 있는 세트가 이 아이의 모든 기기(아이폰·태블릿)에 똑같이 들어가요. 아이 기기에서 만들거나 고친 세트도 여기로 올라와요. 보호자가 만들어 보내면 아이 기기가 다음에 앱을 열 때 들어가요.

    📬 오늘의 단어 설정

    켜 두면 매일 정한 시각에 아이 수준에 맞는 단어를 만들어 아이 홈에 ‘오늘의 단어’ 카드로 보여 줘요. 복습(최근 틀린 단어) 최대 3개 + 새 단어로 채우고, 새 단어는 아이의 최근 세트(교재) 수준을 기준으로 AI가 고릅니다.

    제한 시간은 이 아이의 모든 시험에 적용돼요(오늘의 단어가 꺼져 있어도). 시간이 지나면 그 문제는 ‘모름’으로 기록되고, 앱 밖에 나가 있어도 시간은 흐릅니다. 아이 기기가 다음에 앱을 열 때부터 적용돼요.

    📉 자주 틀린 단어 (최근 2주)

    🕒 기록

    🔒 보호자 설정 · AI 연결 설정 필요

    보호자가 한 번만 설정합니다. 사진 속 단어는 가족용 AI 서버(Cloudflare Worker)를 거쳐 Claude가 읽어 줍니다. 서버 주소와 접속 코드는 이 기기에만 저장되며 백업에 포함되지 않습니다. 사진은 읽는 동안만 전송되고 저장되지 않습니다. 서버 만드는 방법은 저장소의 worker/README.md를 보세요.

    👨‍👩‍👧 가족 기록함 꺼짐

    아이 기기: 보호자 폰의 ‘아이들’ 탭에서 만든 아이 코드 6자리를 넣거나 아이 전용 링크를 열면 이 기기가 그 아이로 연결돼요. 연결되면 시험을 마칠 때마다 점수·틀린 단어가 가족용 AI 서버에 저장되어 보호자 폰에서 볼 수 있고, 오늘의 단어도 받아요. 세트도 아이 단위로 맞춰져요: 이 기기에서 만든 세트는 같은 아이의 다른 기기와 보호자 폰에 올라가고, 보호자가 보낸 세트는 여기에 들어와요(기본 예제 세트는 연결 뒤 사라져요). 단어별 전체 답안은 보내지 않아요. 위의 AI 연결(접속 코드)이 먼저 필요해요. 같은 아이의 아이폰·태블릿에는 같은 코드를 넣으세요.

    🎤 마이크·음성 인식 점검
    현재 브라우저의 마이크 사용 가능 여부를 확인하는 중…
    버튼을 누르면 브라우저가 마이크 권한을 요청합니다. 권한은 사용자가 직접 허용해야 합니다.
    Android 태블릿에서 마이크가 안 될 때
    1. 다운로드 파일이나 앱 안 미리보기 대신 이 HTTPS 주소를 Chrome에서 직접 여세요.
    2. ① 권한 요청 → 브라우저에서 허용 → ② 음성 인식 시험 순서로 누르세요.
    3. Chrome → 설정 → 사이트 설정 → 마이크에서 이 사이트의 차단을 해제하세요.
    4. Android 설정 → 애플리케이션 → Chrome → 권한 → 마이크를 허용하세요. 기기의 전체 마이크 접근 스위치도 확인하세요.
    5. 네트워크 오류라면 인터넷 연결을 확인하세요.

    음성 인식 과정에서 음성이 브라우저 제공업체의 서버로 전송될 수 있습니다. 이 앱은 음성을 저장하거나 업로드하지 않습니다. 영어 읽기 판정은 음성 인식 텍스트 기준이며 전문적인 발음 평가가 아닙니다.

    바로 쓸 수 있는 대안: 시험에서 입력칸을 터치 → 휴대폰 키보드의 🎤로 말하면 앱이 채점합니다. 키보드의 🎤는 앱의 파란 마이크 버튼과 다른 기능입니다.

    💾 백업
