          🔒 보호자 설정 · AI 연결 설정 필요

          보호자가 한 번만 설정합니다. 사진 속 단어는 가족용 AI 서버(Cloudflare Worker)를 거쳐 Claude가 읽어 줍니다. 서버 주소와 접속 코드는 이 기기에만 저장되며 백업에 포함되지 않습니다. 사진은 읽는 동안만 전송되고 저장되지 않습니다. 서버 만드는 방법은 저장소의 worker/README.md를 보세요.

          👨‍👩‍👧 가족 기록함 꺼짐

          아이 기기: 보호자 앱(‘매일 영단어 보호자’)의 ‘아이들’에서 만든 아이 코드 6자리를 넣거나 아이 전용 링크를 열면 이 기기가 그 아이로 연결돼요. 연결되면 시험을 마칠 때마다 점수·틀린 단어가 가족용 AI 서버에 저장되어 보호자 폰에서 볼 수 있고, 오늘의 단어도 받아요. 세트도 아이 단위로 맞춰져요: 이 기기에서 만든 세트는 같은 아이의 다른 기기와 보호자 폰에 올라가고, 보호자가 보낸 세트는 여기에 들어와요(기본 예제 세트는 연결 뒤 사라져요). 단어별 전체 답안은 보내지 않아요. 위의 AI 연결(접속 코드)이 먼저 필요해요. 같은 아이의 아이폰·태블릿에는 같은 코드를 넣으세요.

          연결됨: 🧒

          🎤 마이크·음성 인식 점검
          현재 브라우저의 마이크 사용 가능 여부를 확인하는 중…
          버튼을 누르면 브라우저가 마이크 권한을 요청합니다. 권한은 사용자가 직접 허용해야 합니다.
          Android 태블릿에서 마이크가 안 될 때
          1. 다운로드 파일이나 앱 안 미리보기 대신 이 HTTPS 주소를 Chrome에서 직접 여세요.
          2. ① 권한 요청 → 브라우저에서 허용 → ② 음성 인식 시험 순서로 누르세요.
          3. Chrome → 설정 → 사이트 설정 → 마이크에서 이 사이트의 차단을 해제하세요.
          4. Android 설정 → 애플리케이션 → Chrome → 권한 → 마이크를 허용하세요. 기기의 전체 마이크 접근 스위치도 확인하세요.
          5. 네트워크 오류라면 인터넷 연결을 확인하세요.

          음성 인식 과정에서 음성이 브라우저 제공업체의 서버로 전송될 수 있습니다. 이 앱은 음성을 저장하거나 업로드하지 않습니다. 영어 읽기 판정은 음성 인식 텍스트 기준이며 전문적인 발음 평가가 아닙니다.

          바로 쓸 수 있는 대안: 시험에서 입력칸을 터치 → 휴대폰 키보드의 🎤로 말하면 앱이 채점합니다. 키보드의 🎤는 앱의 파란 마이크 버튼과 다른 기능입니다.

          💾 백업

          세트·시험 기록·틀린 단어를 한 파일로 내보냅니다. 가져오기는 새 세트로 복사하며 기존 세트는 그대로입니다. AI 접속 코드는 포함되지 않습니다. Chrome 메뉴 → 홈 화면에 추가로 앱처럼 설치할 수 있습니다.
