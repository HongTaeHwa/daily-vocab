🎤 음성 인식 점검 · 휴대폰용 안내

현재 브라우저의 마이크 사용 가능 여부를 확인하는 중…
버튼을 누르면 브라우저가 마이크 권한을 요청합니다. 권한은 사용자가 직접 허용해야 합니다.
Android 태블릿에서 마이크가 안 될 때
  1. 다운로드 파일이나 앱 안 미리보기 대신 이 HTTPS 주소를 Chrome에서 직접 여세요.
  2. ① 권한 요청 → 브라우저에서 허용 → ② 음성 인식 시험 순서로 누르세요. 권한 허용과 음성 인식 서비스의 작동 여부는 별개입니다.
  3. Chrome → 설정 → 사이트 설정 → 마이크에서 이 사이트의 차단을 해제하세요.
  4. Android 설정 → 애플리케이션 → Chrome → 권한 → 마이크를 허용하세요. 기기의 전체 마이크 접근 스위치도 확인하세요. 메뉴 이름은 기기마다 다릅니다.
  5. 네트워크 오류라면 인터넷 연결을 확인하세요. 권한이 허용되어도 브라우저·기기·관리자 정책에 따라 음성 인식을 사용할 수 없을 수 있습니다.

음성 인식 과정에서 음성이 브라우저 제공업체의 서버로 전송될 수 있습니다. 이 앱은 음성을 자체 저장하거나 업로드하지 않습니다.

바로 사용 가능한 대안: 단어를 풀 때 입력칸을 터치 → 휴대폰 키보드의 🎤 버튼 → 영어 단어나 한국어 뜻을 말하세요. 음성으로 입력된 글자를 앱이 채점합니다. 키보드의 🎤는 앱 안의 파란 마이크 버튼과 다른 기능입니다.
중요: 다운로드한 file:// 파일은 권한을 허용해도 웹 음성 인식이 차단될 수 있습니다. 음성 자동 채점을 원하면 HTTPS 웹주소에 게시한 뒤 Chrome에서 열어야 합니다. 마이크 권한은 보안상 웹앱이 자동 승인할 수 없습니다.

2. 한국어 뜻 말하기

음성으로 입력한 글자를 확인·수정한 뒤 정답 확인을 누르세요.

한국어 뜻을 말하려면 아래 입력칸을 누른 다음 키보드 🎤를 누르세요. 글자가 입력되면 정답 확인을 누르세요.

단어를 통째로 읽지 말고 알파벳 이름을 차례로 말하세요. 예: C, A, T → cat. 변환된 철자를 확인·수정한 뒤 정답 확인을 누르세요.

갤럭시 S펜 손글씨 입력 방법
  1. ‘S펜·키보드로 입력’을 누르거나 정답 입력칸을 S펜으로 터치하세요.
  2. 삼성 키보드 도구 모음의 손글씨 아이콘(없으면 ⋯ → 손글씨)을 선택하세요.
  3. 한글 → 영어 시험은 키보드 언어를 English로 바꾸고, S펜으로 영어 철자를 쓰세요. 한국어 뜻은 한국어로 씁니다.
  4. 삼성 키보드가 변환한 글자가 정답 입력칸에 들어오면 확인·수정하고 ‘정답 확인’을 누르세요.

지원 기기에서는 설정 → 유용한 기능 → S펜 → S펜으로 텍스트 입력을 켜서 입력칸에 바로 쓸 수도 있습니다. 메뉴·지원 여부는 기기와 One UI 버전에 따라 다릅니다. 손글씨 인식은 기기의 삼성 키보드가 처리하며, 웹앱이 손글씨 모드를 자동으로 켜지는 못합니다.
